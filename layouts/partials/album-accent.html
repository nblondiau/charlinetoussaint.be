{{- /* Accent colour derived from the album's rank in the grid, spread over the colour wheel (https://en.wikipedia.org/wiki/Harmony_(color)): the step is 360°/albumcount, so the hues are always evenly spaced and never repeat — 3 albums land on a triadic scheme (120°), 4 on a tetradic/square one (90°), 6 on a hexadic one (60°), 12 on one hue per hour of the wheel (30°). Rank (not the raw weight) is used so that gaps in the weights do not unbalance the spacing. Lightness alternates with the rank's parity and the saturation is raised until neighbouring hues are told apart at square size. Returns the `style` declaration for the square in front of the album title. */ -}} {{- $baseHue := 6.0 -}} {{- /* the muted terracotta the palette was built around */ -}} {{- $saturation := 60 -}} {{- /* hand-tuned: enough chroma to separate 30° steps, no further; at these lightnesses the 40-80° hues still read olive rather than yellow */ -}} {{- $albums := (where site.RegularPages "Type" "albums").ByWeight -}} {{- $n := math.Max 1 (len $albums) -}} {{- $index := 0 -}} {{- range $i, $p := $albums }}{{ if eq $p.RelPermalink $.RelPermalink }}{{ $index = $i }}{{ end }}{{ end -}} {{- $hue := int (math.Round (mod (add $baseHue (mul $index (div 360.0 $n))) 360.0)) -}} {{- $light := cond (eq (mod $index 2) 0) 42 50 -}} {{- return printf "--accent: hsl(%d %d%% %d%%)" $hue $saturation $light -}}
